# Lancer les composants (ordre obligatoire)

Ouvrir 3 terminaux dans le dossier tp4/.

## Terminal 1 — Manager
```bash
python3 manager.py
```

## Terminal 2 — Minion(s)
Possibilité de lancer plusieurs minions, chacun dans un terminal.
```bash
python3 run_minion.py
```

## Terminal 3 — Boss (envoi des tâches)
```bash
python3 run_boss.py
```

# Arrêt

run_boss.py se termine automatiquement

arrêter les minions et le manager avec Ctrl+C
